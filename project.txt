1. PROJECT OVERVIEW
================================================================================

A fully automated DevOps project that deploys a static HTML/CSS website to AWS
using a modern, agentic infrastructure-as-code stack. The project demonstrates:

  - Static site hosting via AWS S3 + CloudFront CDN
  - Infrastructure-as-Code using Terraform
  - Keyless CI/CD via GitHub Actions + AWS OIDC
  - Claude Code AI agent automation for DevOps tasks
  - Safety hooks, custom agents, and reusable skill commands

The site content is an "Agentic AI Platform" landing page.

  Frontend:

12. CONVENTIONS & RULES
================================================================================

  - All infrastructure changes go through Terraform — never via AWS Console
  - All CI/CD changes go through GitHub Actions — no manual S3 uploads in prod
  - GitHub OIDC auth only — no long-lived AWS access keys ever stored
  - Terraform state backend uses S3 + DynamoDB locking (no local state in prod)
  - backend.hcl and terraform.tfvars are gitignored (contain account-sensitive data)
  - AWS credentials are in .claude/settings.local.json (gitignored, not .mcp.json)
  - All Terraform resources tagged with Project and Environment
  - Use data sources (aws_caller_identity, aws_region) — never hardcode ARNs
  - S3 buckets: always private, public access blocked, AES256 encryption
  - CloudFront: OAC over OAI, HTTP → HTTPS redirect, TLS 1.2 minimum
  - IAM: least privilege, no wildcards, OIDC conditions scoped to repo+branch
